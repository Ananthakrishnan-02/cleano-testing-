# Cleano – website

React + Vite landing page for Cleano Cleaning Service, Trivandrum.

## Edit your details
Open `src/App.jsx` and change `PHONE`, `PHONE_DISPLAY`, `EMAIL` and `LOGO_SRC` at the top.
Services, steps and FAQ text are the arrays right below.

## Run locally
    npm install
    npm run dev

## Deploy on GitHub Pages
1. Push this folder to a GitHub repository (branch `main`).
2. Repo > Settings > Pages > Source: **GitHub Actions**.
3. Each push to `main` builds and publishes the site. The link appears in the Actions run.
